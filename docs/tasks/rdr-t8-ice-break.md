# 红龙 T8：破冰模式（对方挂着寒冰屏障时，两回合斩杀）

先读 `docs/tasks/_common.md`，再读 `docs/tasks/rdr-t4-setup-lines.md`（准备线、完整公式、锁定跟手都是那本做的）和
`docs/research/red-dragon-card-model.md` 里阿莱克丝塔萨一节（鲨鱼下战吼是**两次独立的 8**，不是一次 16）。

## 用户的原话（2026-10-14）

> 帮我评估红龙公式功能是否能新增支持破冰模式。在对方挂有奥秘的情况下，支持通过点击浮窗内新增的按键，切换成破冰模式：
> 计算破冰最优解，破冰逻辑：假定对方挂的奥秘为“寒冰屏障”，因此斩杀逻辑变为这回合触发对对方超出剩余生命值的伤害，
> 把对方奥秘触发。并且在下回合在不卡格子的情况下能实现对对方剩余血量的计算斩杀。公式的计算逻辑为以上的最优解，试着实现。

## 口径（用户不在，这些我先定了；你觉得哪条不对，照做，把理由写进报告，不要自己改）

1. **寒冰屏障**：敌方英雄将要受到致命伤害（这一次伤害 ≥ 当前血量 + 护甲）时，这一次伤害整个不生效，对方本回合免疫，
   奥秘少一个。之前的伤害照常扣。所以「破冰后对方剩余血量」= 触发那一下之前的血量 + 护甲。
2. **本回合的目标**：把冰打掉。打掉之后本回合还可以接着出牌，为下回合做准备（对脸的伤害已经无效）。
3. **下回合怎么算**：把本回合结束时的局面原样当成下回合起手——场上留下的随从照旧占着格子、光环还在，对方场面不变、
   血量是破冰后的剩余血量、不再免疫；法力 +1（封顶 10）；下回合抽到的牌不算。
   **场上留下的随从下回合的攻击不算伤害**（对面一个冻结 / 嘲讽就没了），英雄武器照算。
   「不卡格子」就落在这里：本回合留在场上的东西越多，下回合能下的越少，由同一套引擎算出来，不另写规则。
4. **最优**：先要「下回合能斩掉剩余血量」（不靠随机抽牌）；都能斩的，下回合伤害超出剩余血量越多越好，
   以 8（一次阿莱触发）为一档；同档取本回合步数少的。只收本回合不靠随机抽牌的线（乐队经理的发现不算随机）。
5. **结论三档**：① 能破冰且下回合可斩 → 给这条线；② 能破冰、下回合没搜到斩杀 → 仍给「下回合伤害 − 剩余血量」最高的那条，
   明确标出还差多少；③ 本回合破不了冰 → 不给线，说破不了。
6. **模式开关**：面板里一个可点的按键，只在对方有奥秘时出现；点一下开、再点关。不进设置页、不存盘、不加设置键。
   开着时面板给破冰线（永远是完整公式，照 T4 准备线的做法跟手划掉，不受揭示档和答题模式影响），不再显示普通斩杀公式
   （它假定没有冰）。换局自动关；轮到我方回合开始时对方已经没有奥秘也自动关。**本回合中途把冰打掉了不关**：
   线上剩下的准备步骤照常跟手，打偏了重算出来的仍是破冰口径（此时对方已免疫，只剩准备步骤，可以是 0 步）。
7. 奥秘不是寒冰屏障（那一下把对方打死了，或触发的是别的奥秘）不用专门处理：局面对不上，走现有的「已偏离，重算」。

- -O 耗时：最慢 1.011 s（`g1-first` T11，撞 40 万态闸门、结论破不了），能破的最慢 0.405 s；没有撞 CPU 兜底（2.6 s）的。
- 实现者对口径的异议（都照做了，留给用户定）：① 「超出按 8 分档优先于步数」会选更长的线（19 个可斩里 5 个比最短的多 1–3 步）；

  ④ 「留场随从不算攻击」实现成它们下回合不能攻击，也不能用来解嘲讽。
- 还剩的风险：没有任何 fixture 里真出现过寒冰屏障，规则只有构造局面的单测；下回合依据线是伤害最高的那条，不是最短的斩杀线；
  读取层只认 `ETC_079e` 一种只在本回合有效的费用附魔。
- 没动但发现的：不开破冰时引擎仍允许指定 / 攻击已免疫的敌方英雄（旧行为，没改以免动回归）；`RedDragonSetupTests` 取每回合第一个边界时
  取到法力刷新之前；`T4PIPE` 的跟随次数两次运行不一样（17 / 15），和耗时有关。
