# Phase 2 / 2.9：骷髅只标死亡的随从

先读 `docs/tasks/_common.md`，再读 `docs/archive/tasks/phase2-27-status-icons.md`（现有图标规则、不变式、三轮 review 的坑）。

## 要什么（用户，2026-10-07）

现状：已打出段里只要牌此刻在坟场就画骷髅，所以用掉的法术、打完的武器都带骷髅（用户实机看到，代码 `PlayerCardZones.zoneStatus` 核实）。用户要的是：

1. **骷髅 = 坟场 = 死亡的随从，只有随从。** 法术、武器、地标、奥秘等非随从牌打出后右端不带状态图标。
2. **坟场要准**：我方（对手侧同理：对方）死亡的每一个随从都要出现，名字是它**死的时候是什么**。用户点名的反例：随从被变形后死亡，坟场里显示的名字不对。
3. **火焰不变**：被弃、被撕、爆牌、牌库里被炸、被偷，规则同 2.7。
4. 礼物图标、数量 / 传说星不变。

## 用户已确认（10-07）

- 没进过手牌、直接召唤上场的衍生物，死了也进我方坟场：进已打出段带骷髅（2.7 的「衍生物不进已打出段」只对还活着 / 非随从的成立）。已打出段变长由 2.10 的滚动解决。
- 变形后死亡：骷髅行记变形后的身份；原牌若是从手牌打出的，另有一行不带图标的原牌（它被打出过，但没死）。

## 默认值（用户没拍板，按这个做，报告里单列）
