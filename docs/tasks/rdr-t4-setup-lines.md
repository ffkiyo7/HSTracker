## 要做出什么

1. 引擎能算「本回合不斩杀、为下回合做准备」的线：打 / 回 16 与预启动两类。准备得好不好怎么评、两类线之间以及同类多条线之间怎么取舍，由你从公式表、组注和用户上面的描述里定，写清依据；拿不准的列进报告让用户定，不要自己拍板。
2. 阿莱对友方回血。
3. 提示规则（10-05 用户定）：
   - 本回合能斩杀 → 照旧给斩杀线，不出准备线（危险时也一样，先斩杀）。
   - 场面危险、斩不了 → 给奶 16 的线（含回合结束留下了什么）；奶 16 凑不出 → 浮窗提示「等死」。
   - 不危险、斩不了 → 不主动推荐准备线。
   - 危险阈值改成 −5。
4. overlay：准备线和斩杀线在同一块面板里要一眼区分。**准备线（奶 16）永远直接显示完整步骤，不受揭示档和答题模式影响**（10-05 用户定：危险时没必要练习）；「等死」同样直接显示。T2c 的避让与不卡顿要求照旧。效果图入口补上新局面，渲染给用户看。

5. **⬜ 最高档显示完整斩杀公式（2026-10-05 用户已确认要做；先交付 T3，等用户反馈后再随 T4 实现）**
   - 起因（10-05 用户提）：每步重算后只显示下一步，跟不上出牌速度。改成在最高揭示档一判出可斩杀，就在浮窗上给整条公式文字版，用户照着打，不用等每一步的重算。
   - 本项只改显示（用户选 A）：仍保持每步重算，不做「锁定这条线 / 标出当前步 / 只有打偏才重搜」。那一部分等用户实测本项之后再定。
   - 文字格式（用户定）：沿用公式表的写法，牌名缩写 + 打完剩余的费用 + 目标，例如「鱼4 狐2 刀2 暗1 牛1 刀0 晦4 舞4」。**只写牌名，不标来源**：回收的复制体和原牌都写「刀」，由用户自己判断打哪张；殒命暗影写「原牌（殒）」。
   - 要处理的点（来自 Codex 10-05 的评估，取舍由你定并说明）：
     - 随机分叉怎么写进文字：乐队经理的选项不算随机；依赖抽牌的写成「抽到 X 才继续」；垂钓这类没法展开后续的写「看结果后重算」。
     - 现有展示规则会在连招中途把 L2 自动降档，公式会突然消失。（10-06 已部分修：设置选「顺序」时斩杀线不再按难度封顶，`RDRevealPolicy.cap(preference:)`；设置为其他档、热键升到顺序时仍会被基础线封到参与牌）
     - 浮窗目前最多两行，避让时还会删行，完整公式需要多行布局，不能截掉后半段。
     - 「过时」状态会隐藏所有建议，这一点要保持。
     - 答题模式下不显示完整公式。
